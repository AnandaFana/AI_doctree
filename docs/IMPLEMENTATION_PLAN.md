# v1 教学实现记录

本文记录 v1 详细治理功能的实现顺序。当前默认路线是 Markdown 目录说明与轻量树图，见 [Markdown 节点协议 v2](MARKDOWN_PROTOCOL_V2.md)；下列步骤用于解释仍保留的教学样例与详细功能。

1. 固定测试目录与来源范围，记录现有内容及扫描范围的内容指纹。
2. 建立 README 节点协议、配置驱动的旁路映射，以及两个小型样例。
3. 实现受限扫描、持久索引、上下文导出、交付导入、版本检查和自底向上汇总。
4. 实现中文树导航、变化筛选、证据预览和状态边界展示。
5. 用教学研究项目和软件交付项目验证语义分组，完成可核对的文档交接。
6. 检验旧版本拒绝、多叶节点更新、重启恢复、幂等和扫描只读边界；记录实际结果。

## 可复用的接入检查

- 使用自有测试目录，确认测试数据与工作目录的实际位置。
- 涉及复制的仓库时，核对 Git 顶层、`.git` 指针、对象共享、符号链接与目录联接，避免误把共享路径视为独立副本。
- 文档写入前检查硬链接与当前文件版本；记录已经存在的修改，不能把它们归因为本次工具操作。
- 扫描授权不包含推送、修改远端或执行来源脚本；此类操作需要各自明确的任务范围。
- 扫描接口、治理状态、可视化和文档说明分别验证，再检查整体交接流程。

## 选择

第一版使用 Python + 本地静态页面。数据采用可读 JSON 原子快照、协议 Markdown 和独立配置；没有数据库或付费模型依赖。扫描仅读取文档，不执行来源仓库代码。语义分组先通过旁路映射试验，保留现有文件位置与历史。

教学输入用于验证版本冲突、幂等、队列恢复和文档表述边界，不构成真实业务或科学结果。运行结果由当次测试日志记录；本文中的实现顺序不能代替实际验证。

# 第四轮：可靠的读取入口与轻量维护提醒

日期：2026-09-13。基于 v0.3.1 的外部审阅，在本地源码与隔离教学夹具中核对后改进；外部报告中的测试数字不作为本轮验证结果。

## 取舍

目录协议继续保存导航与职责，增加的可选维护功能只回答“变化后是否核对过相关说明”。使用 Git、Python 标准库和一个共享 JSON，保留必要的输入版本与备份。实际语义判断、说明质量、治理深度和业务验收交给人或 Agent。

不增加后台监听、任务调度、模型调用、自动正文摘要或所有祖先的强制更新。只有人或 Agent 明确指出父级需要吸收变化，才提示直接父节点；该层再次独立判断。

## 复现与处理

| 外部观察 | 本轮处理 | 回归的关键行为 |
|---|---|---|
| 目标受界面节点上限或 runs 折叠限制 | 直接读取目标、路径祖先、直接孩子 | 351 个同级目录和 runs/current 可定位，无需递归构建整树 |
| 孩子正文挤满 Agent 上下文 | 默认孩子只返回标题、职责、路径；正文按需 | 大正文夹具仍遵守输出预算，截断明确可见 |
| a/b 与 a-b 默认 ID 相同 | annotate 与 cover 统一使用路径哈希 | 两个目录均可连续接入，旧 ID 不改变 |
| 排除范围预检通过，应用时才遇到编码错误 | 预检同时报告全局协议发现结果 | 范围外坏编码提前说明；不自动转码或丢弃既有节点 |
| 业务文件修改，README 未改时无提示 | 可选 Git diff 归属与显式核对记录 | 仅叶子先待核对，旧 token 拒绝，无需更新须有理由 |
| 叶子每次改动可能向所有祖先传播 | 父级保留已吸收版本，只处理新的显式请求 | 新的未核对叶子不撤回旧父级收据；needed 仅提示直接父级 |
| v1 额外交付证据没有进入后续失效检测 | 跟踪证据当前语义版本及缺失状态 | 修改、删除、恢复均触发相关状态核对，原交付保留 |
| v1 部分扫描被当成节点删除 | 不完整扫描拒绝替换完整状态 | 上限失败时索引与状态保持，完整扫描恢复关联 |

补充发现：Git 的 assume-unchanged / skip-worktree 标志可能隐藏源码变化。维护检查只读识别这些标志并报告未完成，不自动清除用户设置。

## 验证方法

单元测试使用临时文件与独立 Git 夹具，覆盖版本冲突、预算、路径边界、忽略内容、删除、幂等及父级影响。`scripts/demo_v2_workflow.py` 复制五节点样例，故意只改源码文本，再按预设决定演练无需更新、需要上级吸收及拒绝旧 token；不执行样例源码，不调用模型，因此它证明工具机制，不代表新一次业务语义验收。

不含本地项目与私有配置的发布检出通过 139/139 单元测试；v2 回放 19/19 检查通过，原有 v1 教学回放 12/12 检查通过。浏览器在独立临时项目中实测：源码新增注释后，节点和说明栏显示待核对；读取差异并记录无需更新理由后，刷新显示已记录文档核对，待核对数归零。目录树保留为主要页面。

便携安装包含 13 个工具文件，合计约 201 KiB（不含运行后缓存、原文备份和项目根的共享指引）；关闭第三方包加载后也可导出上下文。默认教学配置扫描 3 个项目、15 个节点，无警告。旧扫描上限失败经接口演练确认：CLI 返回 2、HTTP 返回 400，索引与状态字节保持不变。

本轮实测环境为 Windows、Python 3.14；其他平台尚未进行本轮实机验证。没有增加第三方运行依赖。完整日志、计划、原文备份和临时回放路径保存在被忽略的 `artifacts/v4/`，不随工具发布。

## 自身使用与仍交给使用者的责任

工具自身的根、doctree、docs、web、tests 已建立五份有真实内容的 v2 说明，使用 `scripts/sync_self.py` 维护导航；独立教学样例和本地项目不并入这份导航。`examples/v2/` 提供另一组可阅读的五节点教学内容。

维护记录只保存固定 Git 基线及每个节点最近声明；版本历史依赖正常 Git 提交与本地备份。大型仓库可能达到文件或字节预算，基线也可能随时间增长。当前会明确报告限制，不静默宣称已核对，也不增加自动归档系统。

目录说明仍须按用户选定范围建立；普通 Git 忽略文件不在维护检查范围内。`updated` 与 `no_change` 是人或 Agent 的声明，不能替代测试、业务验收或身份认证。覆盖范围排除并不等于彻底忽略来源发现，编码和项目边界需使用者据实处理。

尚未执行跨项目的一周真实试点。后续由用户选择项目、分支和范围，记录找上下文耗时、收尾耗时及故意漏更是否被发现，再判断是否需要更多能力；本轮没有修改其他真实项目或其远端。

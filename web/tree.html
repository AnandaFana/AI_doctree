A SHARED WAY TO READ

先确定整理范围，再连接目录说明。

由用户选择需要整理到哪一层，Agent 可以提出建议。README 的管理范围与页面的展开深度分别设置。

  1. 按任务选择治理深度

    有独立职责、需要频繁交接的目录可以接入 README 协议；无需给每个产物目录都添加说明。页面“尚无 README”仅帮助定位，可按需要接入。

  2. 沿最近的 README 补齐上下文

    先读本层说明；没有说明时向上寻找最近的 README，确认目标、约束和子目录入口。职责与结论由人或 Agent 编写，工具维护父子导航。

  3. 完成后更新受影响的说明

    更新本次工作的目录说明。若影响上层进展或结论，再核对父目录；收到上级约束变化时，也检查受影响的子目录。

“展开 1 / 2 / 3 层”只改变页面展示，不创建 README，也不改变治理范围。统计仅覆盖已扫描目录，未展开内部不视为已覆盖。“已接入”表示存在协议，不表示工作或科学结论已验收。
